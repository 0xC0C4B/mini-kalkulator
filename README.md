# Mini kalkulator

Učni projekt za preizkušanje Gita: preprost kalkulator z enotskimi testi.

## Zagon

```bash
python kalkulator.py 8 + 2
python kalkulator.py 8 / 2
python -m unittest discover -s tests -v
```

## Podprte operacije

`+`, `-`, `*`, `/`. Deljenje z ničlo sproži `ValueError`.

## Razvoj

Nova funkcionalnost naj se razvija v namenski veji in pred združitvijo preveri s testi.
